# Cornet custom themes

Custom themes are independent visual experiences. They may use gradients, glow, blur, animation, shaders, textures and other effects.

## Cosmic Panda

Cosmic Panda is intentionally inspired by the YouTube 2012 / Cosmic Panda era, but is not a historical reproduction. Its visual layer can be more expressive while retaining the same era's dark, dimensional, glossy direction.

### Hard rule

Custom themes NEVER change a user's channel layout. In particular, they must not override `channel_style`, `channel_info_layout`, profile layout, routing, or any other user-selected structural preference.
